# 기념일/선물

기념일 키워드는 단독 키워드보다 조합형 검색 의도가 강하다. C 자동화는 아래 축을 조합해 후보를 만들고, 후보의 `category`는 `기념일/선물`로 둔다. 실제 쿠팡 상품 조회에는 `coupangSearchTerm`에 담긴 상품군을 사용하고, 네이버 연관검색어와 검색량 검증을 거친 뒤 `data/keyword-candidates.json`에 `pending`으로 추가한다.
