## 4. 디자인과 톤

- 디자인: WordPress 테마 의존도를 낮추기 위해 본문 wrapper, 비교표, CTA 버튼에 inline style 적용
- 상품 이미지: 쿠팡 파트너스 API의 `productImage`를 상품 섹션별로 삽입
- 대표 썸네일: 생성형 이미지 API가 아니라 HTML/CSS 카드 렌더링 후 JPEG로 캡처
- 비교표 개선: 사진, 상품명, 가격, `바로가기` 링크를 포함하고 `caption`, `thead`, `th scope`를 적용한 선 있는 기본 테이블로 변경
- CTA 개선: 단순 파란 버튼에서 주황 계열 고대비 버튼으로 바꾸고 각 상품 섹션 중앙에 정렬
- 대표 썸네일 개선: 1200x630 비율, 큰 제목, 실제 상품 이미지, 적은 텍스트를 기준으로 한 평범한 정보형 카드로 변경
- 톤: 마스터 큐레이터 H 기반이지만 과한 하이엔드 문체는 줄이고 생활가전 구매 기준 중심으로 조정
- 구조: 도입, 구매 기준, 비교표, 상품별 분석, 최종 선택 기준, 쿠팡 파트너스 고지
- CTA: 각 상품 섹션마다 `쿠팡에서 확인하기` 버튼 삽입
- 제목 중복 방지: WordPress 테마가 글 제목을 출력하므로 본문 HTML의 `<h1>`은 제거
- 운영 방식 변경: 현재 품질 기준에서는 `WP_AUTOPUBLISH_STATUS=publish`로 공개 발행
